# AGENT.md — Obsidian Vault Governance Protocol

## 📌 Core Identity

This vault is a **living knowledge base** synced across 2-3 PCs. It serves as:

- A project tracking hub
- A personal knowledge management (PKM) system
- A decision log and reference archive

**Golden Rule**: *If it's not useful tomorrow, it doesn't belong here.*

---

## 🚦 Push / No-Push Rules

### ✅ ALWAYS PUSH (Commit to Vault)

| Category | Examples |
| :--- | :--- |
| **Project updates** | Status changes, blockers, next steps, decisions made |
| **Meeting notes** | Summaries, action items, decisions, follow-ups |
| **Research findings** | Summarized insights, links, quotes with context |
| **Daily logs** | What you worked on, what you learned, what you're thinking |
| **Structured templates** | Any note that follows a folder template (see below) |
| **Links between notes** | `[[WikiLinks]]` connecting related ideas |
| **Metadata** | Frontmatter tags (`#project/active`, `#status/done`) |
| **Reference material** | External resources you'll reuse (code snippets, commands, configs) |

### ❌ DO NOT PUSH (Keep Local / Scratch)

| Category | Examples |
| :--- | :--- |
| **Transient TODOs** | "Write email to X" or "Check calendar"—these belong in tasks app |
| **Raw data dumps** | Unfiltered copy-paste from web without summarization |
| **Personal ephemera** | Grocery lists, one-off reminders, temporary scratch |
| **Large binaries** | Images, PDFs, or files > 5MB (use external storage) |
| **Redundant logs** | Duplicate information already captured elsewhere |
| **AI-only scratch** | Chain-of-thought or internal reasoning that adds no human value |
| **Syncing noise** | Files that constantly change (e.g., `.obsidian/workspace.json`) |
